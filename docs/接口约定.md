# 接口与研究口径

核对日期：2026-10-18。先读取工作区 `tushare_doc/期货数据.md`，结合官方接口说明和真实响应实施；接口权限以用户账号的实时规则为准。

| 接口 | 用途 | 单次保护上限 | 请求方式 |
| --- | --- | ---: | --- |
| fut_basic | 上期所合约信息，筛选 fut_code=CU，包含已到期合约 | 10000 | 元数据24小时缓存 |
| fut_trade_cal | 上期所交易日历，包含休市 | 10000（内部保护值，非官方额度承诺） | 每段最多365日历天 |
| fut_mapping | CU.SHF 的真实主力月合约 | 2000 | 按交易日缺口、最多120日/段 |
| fut_daily | 原始月合约 OHLC、结算、量、持仓 | 2000 | 指定真实合约、最多120交易日/段 |
| ft_limit | 涨跌停与最低保证金率 | 4000 | 指定真实合约、最多120交易日/段 |
| fut_settle | 历史结算及费率 | 1600 | 指定真实合约、最多120交易日/段 |

行情类响应达到行数上限即递归切分，单日仍达上限则失败。用户可调低请求保护上限，不能通过配置调高已知官方上限。账号与接口预算取较小值，默认30次/分、并发1，不压测账号额度。所有重试也占预算。

覆盖清单用接口、真实合约、日期和口径版本记录；休市通过日历识别，未上市和到期后不请求。无成交保留原始成交量0；空响应不当成功，缺口保存并显示错误。普通历史同步不重拉，尾部检查默认关闭，可设置最后若干交易日及最短复查小时数。显式修复另有任务内分段检查点。

使用官方 SDK 的 DataApi 查询协议，传输实现使用 requests.Session 调用官方根端点 `https://api.tushare.pro`，检查HTTP状态和业务code。SDK旧传输出现过“IP数量超限”，本次单日对照和后续140次请求成功，不能据此确定账号IP记录或网络出口的根因。

价格单位为元/吨；每手数量读取商品合约 `per_unit`，本次CU为5吨/手；最低价位配置默认10元/吨。成交量、持仓量保留原值；2020年前后的统计变化在量持仓变化特征中分段预热，不粗暴将全部字段除二。`fut_trade_param` 不用于填充上期所参数。

主力映射与日线的历史准确可用时刻未能得到逐条证实，因此默认 t 日信号在 t+2 交易日首个交易时段 open 执行。夜盘属于供应商给定的 trade_date，不自行按自然日平移。用户改为更短滞后时需要核实可得时点。

信号价格链式衔接新旧合约；交易与盯市使用真实月合约，换月分别平旧开新。历史手续费有歧义时失败，默认固定成本只是研究假设；最低保证金字段不能代表期货公司实际保证金。样本末端按结算权益报告，未额外强制平仓；若持仓非零，终止平仓费用不在该样本指标中，可从持仓表识别。
