## 1. 当前实际使用什么

当前已完成的两次挖掘任务 `mine_20261018_014101_63be3c49`、`mine_20261018_013859_a5d7418e` 均使用 `cu_6bdd3416eb40e69dba65`，研究期为2024年。已下载的2025—2026新快照可供新任务选择，但现有历史因子不会自动切换数据或重新计算。

研究对象是Tushare主连映射 `CU.SHF`，不是固定到期合约。每天先从映射表选出实际月份合约，取该合约原始日线。研究价格经过因果比例衔接；回测成交和盯市使用实际月份合约的原始开盘/结算价格。

| 层次 | 当前处理 | 是否真实可交易价格 |
| --- | --- | --- |
| 原始月合约 | 每个 ts_code 独立保存 | 是，但成交还受时间和流动性约束 |
| 看板主连 | 按日映射直接拼接，未复权 | 换月两天不能当同一资产连续收益 |
| 挖掘信号价格 | 对映射月合约OHLC按已知比例衔接 | 否，仅用于特征计算 |
| 回测执行 | 默认滞后2交易日取决策日映射，平旧开新、按原价算盈亏 | 按真实月合约模拟，不能保证实际成交 |

## 3. 已有后处理是否正确

当前换月到新合约的信号调整系数为：

```text
A_new = A_old × C_old(t−1) / C_new(t−1)
signal_OHLC(t) = raw_OHLC_of_mapped_contract(t) × A_new
```

使用换月前一交易日两份合约的价格，而非未来价差重算历史。这样切换日信号收益对应新合约自身的价格变化，不把新旧合约价差当作当日行情涨跌。它是一种明确的信号构造约定，并不等于持仓策略的实际展期收益。

成交量和持仓量不乘价格调整系数。当前相对量持仓先在每份合约内计算，再按日映射；比直接拼接原始量持仓好，但切换时所取合约及其生命周期仍改变，残余迁移效应尚未完全消除。

特征使用历史统计标准化并保留预热缺失；标准分方向不等于原始涨跌/增减仓方向，具体见[因子组合方案](沪铜期货因子组合与特征改造方案.md)。

## 4. 是否适合当前目标

**适合沪铜日频价格方向、趋势/反转及量价持仓因子的第一版研究；不适合单靠它完成完整的期货因子库。**

| 研究目标 | 当前主连及月份底表是否适合 | 后续要求 |
| --- | --- | --- |
| 沪铜趋势、反转、价格波动 | 适合，保留因果连续信号和真实合约回测 | 增加多年样本及数据核验 |
| 量持仓交互 | 有条件适合 | 同合约对齐、生命周期分层、换月敏感性检查 |
| 期限结构、展期背景 | 当前主连不足 | 补齐同日近远月及选择规则，不用复权价计算价差 |
| 跨期套利 | 当前单腿回测不足 | 双腿成交、成本与保证金核算，独立工程范围 |
| 库存、仓单、现货基差 | 当前快照不足 | 接入对应数据与可得时点 |
| 同一固定月合约长期挖掘 | 不建议作为多年研究主样本 | 生命周期短且远月早期可能不活跃；可作局部对照 |

快照最新不等于训练样本够长。2025—2026研究区只有431个交易日，2024只有242个；它们可用于流程和有限假设验证，暂不足以支持大量表达式反复搜索后得出稳健结论。正式研究应补齐此前讨论的多年训练区间及预热；不能把已用于筛选的区间重新当未见测试。

## 5. 建议增加的后处理，按优先级

### P0：保留分层并显式版本化

- 原始行情不覆盖，不重复对现有信号做第二遍复权。
- 将实际合约、映射日、信号调整系数、连续价格方法、特征版本写入可查看的研究数据说明。
- 连续信号价格用于收益/趋势特征，原始月合约价格用于实际盈亏、涨跌停、名义金额和近远月价差。
- 每个特征注明输入口径：原始值、标准分或标志，不把标准分当原始正值。

### P0：标记换月与生命周期，不盲目删样本

- 保存当日是否切换、距已发生切换的交易日数、距已知最后交易日的日历天数。
- 对每个因子分别查看换月附近与其他日期的值分布、仓位变化和成本后贡献，窗口在开发前约定。
- 不能用“未来几天将发生主力切换”作为实时特征；按未来换月日划窗口只能用于事后诊断。
- 不默认删除所有换月前后5天：这样会周期性删去大量正常样本，且可能带来选择偏差。

### P0：价量持仓交互按同合约计算

- `oi_change5` 是当前月合约自身变化，而当前 `price_oi` 的价格项来自连续5日收益，5日内可能包含别的合约。
- 建议新增“同一真实合约5日收益 × 该合约5日OI变化”作为单独版本，与当前连续价格版本作对照。
- 到期前减仓和远月转活跃不直接归因供需；先分层验证，必要时再引入按距到期时间的历史基准，不能用全生命周期未来数据拟合当时基准。

### P0：完整性与异常隔离

- 核对日历、主力映射、实际持仓合约、换月前日新旧报价，以及必要涨跌停参数。
- 价格离群先交叉核验，不能用任意收益截断、前向填充或补0静默修复。
- 152条结算参数缺失继续保留审计；固定成本和历史费用模式的可用范围分别标记。

### P1：映射可得时点与独立选约对照

- 当前历史映射精确发布时间未逐条证实，默认2日执行延迟只是保守处理，不是已完成点时可得性证明。
- 保留供应商映射作为MVP基线；后续可以用截至上一交易日可见的成交/持仓、到期过滤和事前固定切换规则建立独立选约版本。
- 检查来回切换、低流动性、接近交割及持仓迁移；一旦改选约规则，生成新版本，不回写旧快照。
- 补齐近远月后再扩展期限结构，不把单一主连包装成完整曲线。

## 6. 推荐决定

继续以 `CU.SHF` 对应的因果连续信号作为价格类研究主线，真实月合约作为量持仓计算与回测底座；不改成只研究CU2611，也不直接换成行情软件的未知复权主连。

下一步先做换月/生命周期标记、同合约价持仓对齐、数据质量核验与多年训练数据补齐，再扩展近远月曲线。新建任务必须显式确认快照，旧任务和旧因子不会因下载了新数据自动更新。
