## 组合列表

### 接口介绍

接口：p_list
描述：便于用户在基于AI应用或Vibe Coding过程中产生的选股结果形成长期记忆，Tushare提供了自选股组合功能。本接口可以查询你的自选组合信息，不加参数查询出所以自定义组合

### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| name | str | N | 组合名称 |

### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| id | int | Y | 主键 |
| name | str | Y | 名称 |
| desc | str | Y | 描述 |
| create_time | datetime | Y | 创建时间 |
| update_time | datetime | Y | 修改时间 |

### 代码示例

```
# 初始化pro接口实例
pro = ts.pro_api()

# 查看我的组合列表
df = pro.p_list()
print(df)

# 查看某个组合的成份列表
df = pro.p_get(name="我的股票池", fields="ts_code,create_time,update_time")
print(df)
```

## 组合保存

### 接口介绍

接口：p_save
描述：创建或修改自选股组合
限量：每个用户最多200个组合，如需更多请联系管理员

### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| name | str | Y | 组合名称 |
| desc | str | N | 描述 |
| items | list | Y | 成份列表; 每个元素包含  ts_code:str ts_type:str weight:float name:str desc:str |

### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| id | int | Y | 主键 |
| ts_code | str | Y | 成分代码 |
| ts_type | str | Y | 成份类型 |
| name | str | Y | 名称 |
| desc | str | Y | 描述 |
| weight | float | Y | 权重 |
| create_time | datetime | Y | 创建时间 |
| update_time | datetime | Y | 修改时间 |

### 代码示例

```
import tushare as ts

pro = ts.pro_api()

# 选取股票列表
df = pro.stock_basic()
df_stock = df.head(10)
print(df_stock)

# 保存到自定义组合
p_items = df_stock[["ts_code", "name"]]
df_p1 = pro.p_save(name="我的股票池", items=p_items.to_dict(orient='records'))
print(df_p1)
```

## 组合删除

### 接口介绍

接口：p_delete
描述：删除自选股组合

### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| name | int | Y | 组合名称 |

### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| status | bool | Y | 是否执行成功 |

### 代码示例

```
# 删除组合(我的股票池)
df=pro.p_delete(name="我的股票池")
```

### 数据结果

```
       status
    0   True
```
